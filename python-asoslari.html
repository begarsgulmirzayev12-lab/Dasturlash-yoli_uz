BOSHLANG'ICH · 1-DARS

Python asoslari

Python — sodda va tushunarli sintaksisi tufayli dasturlashni o'rganish uchun eng yaxshi tillardan biri. Shu darsda o'zgaruvchilar, shartlar, sikllar va funksiyalarni o'rganasiz.

O'zgaruvchilar

O'zgaruvchi — ma'lumotni saqlash uchun "quti" deb tasavvur qiling. Pythonda o'zgaruvchi yaratish uchun maxsus so'z kerak emas — shunchaki nom bering va qiymat bering:

ism = "Aziz" yosh = 25 talaba = True # Chiqarish uchun print() ishlatiladi print(ism, yosh)

Bu yerda ism — matn (string), yosh — butun son (integer), talaba esa mantiqiy qiymat (boolean, ya'ni to'g'ri/noto'g'ri).

Shartli operatorlar

if, elif va else yordamida dastur ma'lum shartga qarab turli harakat qilishi mumkin:

yosh = 17 if yosh >= 18:   print("Kattasiz") elif yosh >= 13:   print("O'smirsiz") else:   print("Bolasiz")

Muhim: Pythonda qavslar o'rniga bo'sh joy (indentatsiya) ishlatiladi — har bir blok bir xil miqdorda bo'sh joy bilan boshlanishi kerak.

Sikllar (loop)

Bir xil amalni bir necha marta takrorlash uchun for yoki while sikllaridan foydalaniladi:

# 1 dan 5 gacha sonlarni chiqarish for son in range(1, 6):   print(son) # while sikli hisoblagich = 0 while hisoblagich < 3:   print("Salom!")   hisoblagich += 1

Funksiyalar

Funksiya — qayta-qayta ishlatiladigan kod bo'lagi. def so'zi bilan e'lon qilinadi:

def kvadrat(son):   return son * son natija = kvadrat(5) print(natija) # 25

Funksiyalar kodni tartibli va qayta ishlatsa bo'ladigan qilib tashkil etishga yordam beradi.

Mashq

1-5 gacha sonlarning yig'indisini hisoblaydigan for sikli yozing va natijani print() orqali chiqaring.

Qiyinroq: yoshni parametr sifatida qabul qiladigan va "kattasiz" yoki "bolasiz" qaytaradigan funksiya yozing.
